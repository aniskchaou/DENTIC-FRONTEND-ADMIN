The Marketing Campaigns module provides a comprehensive interface for managing marketing campaigns within the Dentic application. When users access this module, they are presented with a clear, organized table listing all existing campaigns. Each campaign displays essential information such as the campaign name, type, target audience (including age and treatment history), message template, scheduled date, and current status. The status is visually highlighted using colored chips, making it easy to distinguish between scheduled, active, completed, draft, and cancelled campaigns.

At the top of the interface, users will find action buttons for creating a new campaign, deleting a selected campaign, and refreshing the campaign list. These buttons are styled with an outlined appearance for clarity and are fully translatable, ensuring accessibility for users in different languages. To create a new campaign, users simply click the "Create Campaign" button, which opens a modal form. This form guides users through entering all necessary campaign details. Once submitted, the new campaign is added to the table and becomes immediately available for review and management.

Deleting a campaign is straightforward: users select a campaign from the table and click the "Delete" button. A confirmation prompt ensures that deletions are intentional, helping to prevent accidental data loss. The "Refresh" button allows users to reload the campaign list, ensuring they always see the most up-to-date information from the backend.

The module also supports editing campaigns, with a dedicated modal prepared for future enhancements. All user-facing text, including button labels, column headers, and modal titles, is wrapped in translation functions, making the module fully compatible with internationalization standards. This ensures that users can interact with the module in their preferred language, with all interface elements adapting accordingly.

Overall, the Marketing Campaigns module is designed for ease of use, clarity, and flexibility. It empowers users to efficiently manage their marketing efforts, providing all necessary tools for campaign creation, review, and maintenance in a single, intuitive interface.
