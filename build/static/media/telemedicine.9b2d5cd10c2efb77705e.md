# Telemedicine Module 

The Telemedicine module enables clinics to conduct secure and efficient remote consultations with patients using integrated video and audio calls, Google Meet scheduling, and real-time chat. Users can view and manage telemedicine appointments through an interactive calendar, create new sessions, and access detailed information for each scheduled event.

To schedule a telemedicine appointment, users select a patient and doctor, set the session duration and start time, and generate a Google Meet link for the consultation. The module automatically integrates with Google Calendar, ensuring seamless scheduling and access to meeting links. Each appointment displays relevant details, including patient and doctor names, session time, duration, status, and meeting link.

During a telemedicine session, clinicians can enable or disable video and audio, end the call, and communicate with patients via a built-in chat feature. The module supports viewing recent call history, including completed and missed calls, with details such as patient name, call type, duration, and status.

Administrators can manage telemedicine settings, including Google Meet API credentials, and monitor all remote consultations from a centralized dashboard. The module also provides notifications and feedback for key actions, such as creating appointments, joining calls, and copying meeting links.

Overall, the Telemedicine module streamlines remote patient care, supports secure video and audio consultations., and enhances communication between clinicians and patients.
