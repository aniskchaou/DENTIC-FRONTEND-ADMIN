# Equipment Maintenance

The Equipment Maintenance module is designed to help clinics efficiently manage all aspects of their medical and dental equipment. Users can view, add, edit, and delete equipment records, each containing details such as clinic location, equipment name, model number, manufacturer, purchase date, last service date, next service due, status, assigned technician, and maintenance notes.

The module provides powerful filtering and search capabilities, allowing users to quickly locate equipment by name, status, technician, or clinic. Bulk actions are supported for deleting multiple items or updating their maintenance status, streamlining administrative tasks.

Maintenance scheduling is a key feature, enabling users to set up routine checks, repairs, calibrations, cleanings, software updates, and other types of maintenance. Each maintenance event is recorded in the equipment’s history, which can be viewed in a dedicated drawer. Overdue maintenance is highlighted, helping staff prioritize urgent tasks and ensure compliance with safety standards.

Technicians can be assigned to equipment, and notifications are provided for successful actions such as scheduling maintenance, assigning technicians, or updating records. The module also supports exporting equipment data for reporting and importing new records for easy onboarding.

Additional features include QR code generation for quick equipment identification, file attachments for maintenance documentation, and detailed dialogs for viewing and editing equipment information. The responsive design ensures usability on both desktop and mobile devices.
