# Used Technologies

Dentic is built using a modern, modular technology stack that ensures reliability, scalability, and extensibility for dental clinic management. The application leverages a combination of popular frontend and backend frameworks, libraries, and cloud services to deliver a robust user experience and powerful features.

## Frontend

- **React**: The core UI library, providing a component-based architecture for building interactive and responsive interfaces.
- **Material UI (MUI)**: Used for consistent, accessible, and customizable UI components, including icons, data grids, date pickers, and system utilities.
- **Chart.js, Recharts, Plotly.js, React-Chartjs-2, React-Plotly.js**: For advanced data visualization, analytics, and interactive charts.
- **FullCalendar & React-Big-Calendar**: Calendar and scheduling components for appointments and telemedicine.
- **Three.js, @react-three/fiber, @react-three/drei, @pmndrs/xr**: For 3D visualization, including odontogram and jaw models.
- **Bootstrap**: For additional UI styling and layout support.
- **i18next & react-i18next**: Internationalization and localization support for multi-language clinics.
- **Axios**: For HTTP requests and API communication.
- **Redux & Redux Thunk**: State management across the application.
- **React Router**: For navigation and routing between modules.
- **JSPDF & html2canvas**: For exporting and printing documents, certificates, and reports as PDFs.
- **File-Saver & XLSX**: For exporting data to files such as Excel spreadsheets.
- **Moment & Date-fns**: Date and time utilities for scheduling and reporting.
- **Testing Libraries**: @testing-library/react, @testing-library/jest-dom, @testing-library/user-event for unit and integration testing.
- **Other Libraries**: jQuery, popper.js, select-picker, memoize, use-force-update for various UI and performance enhancements.

## Backend

- **Node.js & Express**: The main backend framework, providing RESTful APIs and server-side logic.
- **Database Support**: 
  - **MongoDB (via Mongoose)** for document-based storage.
  - **PostgreSQL & MySQL (via Sequelize, node-postgres, mysql2)** for relational data.
  - **SQLite3** for lightweight local storage.
- **Body-Parser & CORS**: For handling HTTP requests and cross-origin resource sharing.
- **Multer**: For file uploads (e.g., lab reports, images).
- **Nodemailer**: For sending emails and notifications.
- **Swagger (swagger-jsdoc & swagger-ui-express)**: For API documentation and testing.
- **OpenAI, @google-cloud/vertexai, @google-cloud/vision, @xenova/transformers, onnxruntime-node**: For AI-powered features, including image analysis, natural language processing, and advanced diagnostics.
- **Express-Handlebars**: For server-side templating (if needed).
- **FS, Path, URL, HTTP**: Node.js core modules for file and network operations.

## Integrations & Cloud

- **Google Meet & Google Calendar APIs**: For telemedicine and appointment synchronization.
- **Third-Party Payment Gateways**: For billing and online payments.
- **AI & ML Services**: Integration with OpenAI and Google Vertex AI for smart features.

## Build & Development Tools

- **Babel**: For JavaScript transpilation and compatibility.
- **React Scripts**: For building, testing, and running the frontend.
- **ESLint**: For code quality and linting.
- **Browserslist**: For specifying supported browser environments.
