# Dashboard Module

The Dashboard module provides a comprehensive overview of your clinic’s key metrics and activities in a single, easy-to-navigate interface. Upon logging in, users are greeted with summary cards displaying real-time statistics such as the number of patients, appointments, medicaments, certificates, laboratory tests, expenses, doctors, staff, clinics, memberships, and insurance records. These cards offer a quick snapshot of the clinic’s operational status and help users monitor important figures at a glance.

Below the summary cards, the dashboard features a variety of interactive charts, including bar, pie, doughnut, line, polar area, radar, scatter, and bubble charts. These visualizations allow users to analyze trends such as patient growth by month, appointment status distribution, medicament categories, staff attendance, clinic revenue, and more. The charts are designed to help administrators and clinicians make data-driven decisions and identify areas for improvement.The module also highlights top performers, listing the five doctors with the most appointments, the five patients with the most visits, and the five medicaments with the highest sales. This information is valuable for recognizing outstanding contributors and understanding patient and medicament trends.

An integrated appointments calendar enables users to view scheduled appointments by date, with visual indicators for days containing appointments. Selecting a date displays detailed information about each appointment, including patient name, doctor, time, type, status, and notes. This feature streamlines daily planning and ensures that staff are aware of upcoming visits.Finally, the dashboard includes a system health section, showing the status of backend services, API connectivity, and uptime percentage. This helps IT staff and administrators monitor the technical health of the application and quickly identify any issues.

Overall, the Dashboard module is designed to be the central hub for clinic management, providing actionable insights, operational transparency, and efficient access
