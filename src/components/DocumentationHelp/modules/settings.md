# Configuration Module

The Configuration module allows clinic administrators to customize and manage essential system settings for the Dentic application. The module is organized into tabs for easy navigation, covering system information, localization, open hours, AI integration, and telemedicine configuration.

In the **System** tab, users can set the clinic name, address, support email, and choose whether to display the clinic logo.

The **Open Hours** tab provides a simple interface to set the clinic’s operating hours for each day of the week. Administrators can quickly update hours and ensure accurate scheduling for appointments and staff.

The **AI Integration** tab allows users to securely manage their OpenAI API key, which is used for advanced features such as AI-powered suggestions and analytics. The module includes a toggle to show or hide the API key for privacy.

The **Telemedicine** tab is dedicated to configuring the Google Meet API key, enabling seamless integration of telemedicine features for remote consultations.

All settings can be edited in dedicated dialogs, restored to default values, and are saved securely to the backend or local storage. The module provides clear feedback for all actions, ensuring administrators can confidently manage clinic configuration.
